# Design Logos 2027

Agent Skill para criar, adaptar e revisar peças da campanha **Resultados com Propósito** do Centro Educacional Logos.

- [Instruções da skill](skills/logos-2027-design/SKILL.md)
- [Guia original de identidade visual](skills/logos-2027-design/references/DESIGN_LOGOS_27.md)

## Instalar no Codex

Envie esta mensagem em um chat do Codex.

```text
$skill-installer instale a skill em https://github.com/jasonmagave/logos-2027-design/tree/main/skills/logos-2027-design
```

Também é possível usar o script do instalador do Codex pelo terminal, quando ele estiver disponível na instalação local.

```sh
python3 "${CODEX_HOME:-$HOME/.codex}/skills/.system/skill-installer/scripts/install-skill-from-github.py" \
  --repo jasonmagave/logos-2027-design \
  --path skills/logos-2027-design
```

## Usar

```text
$logos-2027-design revise este post de matrícula para o Ensino Médio conforme o guia da campanha.
```
